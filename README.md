# Ordinary Hands

Fake landing pages for AI products that should not exist.

https://coryodaniel.github.io/ordinary-hands/

## How this was made

Everything here was built by dictation. I don't know how to design front ends, so I described what I wanted out loud to an AI coding tool and kept talking until it looked right. It was slow and annoying, and that was the point. I wanted to feel the friction a scammer or a vindictive person would feel getting one of these products built for them, and see how little of it there was.

The AI-isms that slipped through are part of the piece. I'm not taking pull requests that fix the copy or the code.
